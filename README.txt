SourceHub — версия с Telegram, модерацией и профилями

Что добавлено
- Белая тема сайта.
- Русские и латинские ники; можно вводить ник с @.
- @bogMurphy зарезервирован и может принадлежать только администратору.
- Аватары профилей.
- Золотая и белая галочка тестера. Выдаются администратором строго по User UID.
- Админ UID зашит только на сервере: b4174ad4-6dd0-47ff-8e38-2d0a7986a3e0.
- Модерация публикаций: новый сорс получает статус «На модерации» и не появляется в общей ленте до одобрения.
- В профиле администратора появляется панель модерации и выдачи галочек.
- Сессия браузера сохраняется на 365 дней, поэтому код Telegram не нужно вводить при каждом заходе.
- Один Telegram ID по-прежнему привязан к одному SourceHub User ID и одному постоянному 6-значному коду.

Запуск
1. Замени старые server.py и index.html этой версией.
2. Не удаляй sourcehub.sqlite3 и папку uploads — они содержат существующие аккаунты и публикации.
3. Перезапусти сервер:
   python server.py
4. Во втором Termux окне запусти:
   cloudflared tunnel --protocol http2 --url http://127.0.0.1:8080
5. Если URL Quick Tunnel изменился, замени значение const API в index.html на новый https://....trycloudflare.com и заново загрузи index.html на Netlify.

Важно
Quick Tunnel временный. Пока server.py и cloudflared не работают, публичный сайт не сможет обращаться к API.
Новые публикации проходят модерацию. Администратор должен открыть свой профиль, одобрить сорс и при необходимости выдать тестеру галочку по UID.
